# Inquisitors Society — Knowledge Base Sources

## Source Policy

The chatbot uses publicly available information for prototype
development.

Sources are classified according to reliability.

### Priority 1 — Official Institutional Sources

- University of Engineering and Technology Lahore official website
- Official university announcements

### Priority 2 — Official Society Sources

- Inquisitors Society official LinkedIn profile
- Official social media accounts
- Official communication channels

### Priority 3 — Public References

- Public LinkedIn posts
- Public event announcements
- Other publicly accessible references

## Source Verification Rules

1. Do not invent missing information.
2. Do not assume outdated information is current.
3. Prefer official institutional sources over third-party sources.
4. Prefer recent official announcements for time-sensitive information.
5. Preserve source information when adding new knowledge.
6. If information conflicts, prefer the higher-priority source.
7. If reliable information is unavailable, the chatbot should use its
   fallback response.

## Prototype Status

The current knowledge base contains a mixture of publicly researched
information and prototype information.

Official administration-provided documents should replace or validate
prototype information when they become available.
