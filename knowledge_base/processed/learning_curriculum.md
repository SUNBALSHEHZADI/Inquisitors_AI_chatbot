# Inquisitors Society - Learning Curriculum

This curriculum is a learning guide for students exploring AI, Machine
Learning, Data Science, research, and practical technology projects. It is
not a fixed timetable or an official promise about a current course batch.

## Artificial Intelligence

Students can study the foundations of intelligent systems, including:

- What artificial intelligence is and where it is used
- Problem solving, search, logic, and knowledge representation
- Machine learning, deep learning, natural language processing, and computer vision
- Responsible AI, bias, privacy, evaluation, and human oversight

Useful beginner projects include a rule-based assistant, a recommendation
prototype, an image classifier, or a document question-answering assistant.

## Machine Learning

A practical Machine Learning learning path can follow this sequence:

1. Python programming, NumPy, pandas, and basic data visualization
2. Statistics, probability, data cleaning, and exploratory data analysis
3. Features, labels, training data, validation data, and test data
4. Regression, classification, clustering, and dimensionality reduction
5. Evaluation metrics such as accuracy, precision, recall, F1 score, and MAE
6. Overfitting, underfitting, regularization, cross-validation, and pipelines
7. Model interpretation, experiment tracking, and responsible deployment

Practice projects include predicting a numeric value, classifying text,
grouping similar records, and comparing multiple models with an evaluation
report.

## Data Science

Data Science combines domain questions, data, programming, statistics, and
communication. A student can learn to:

- Define a measurable question and identify useful data
- Load, clean, join, and validate tabular data
- Explore distributions, relationships, missing values, and outliers
- Create clear charts and communicate evidence without misleading claims
- Use statistical reasoning and machine learning when appropriate
- Present findings in a reproducible notebook or project report

Good starter projects include an exploratory analysis, a dashboard dataset,
a survey analysis, or a data-backed report that explains limitations.

## Recommended Study Method

For each topic, students should learn the idea, implement a small example,
test it on a real dataset, explain the result in plain language, and record
what did not work. The strongest portfolio projects show the question,
method, evaluation, limitations, and next step.
