# Screenshot Deliverables

This folder contains screenshots captured from the working frontend for the
project demonstration. Recommended states are:

- `chat-open.png` - empty chat with suggested questions
- `chat-response.png` - grounded answer with a clickable official link
- `chat-fallback.png` - unsupported-question fallback
- `chat-support.png` - human support contact panel

Screenshots are generated locally because the chatbot requires the project's
own frontend assets and API configuration.
